================================================================================
                                INTERNSHIP RADAR
================================================================================

Internship Radar is a lightweight web application built for engineering students 
to browse live internship listings and evaluate them—or any pasted job message—
for common scam signals. 

Instead of black-box filtering, every listing receives a transparent trust score 
(1–99) alongside the exact red flags and positive indicators that influenced it.


FEATURES
--------
* Field-Specific Browsing: Filter internships across 8 engineering domains 
  (AI/ML, Cybersecurity, Robotics, Embedded/IoT, VLSI/Electronics, 
  Web/Software, Data Analytics, and Mechanical/CAD).
* Transparent Scam Scoring: Uses a weighted log-odds scoring model to flag 
  common internship scams (e.g., registration fees, WhatsApp/Telegram redirects, 
  unrealistic stipends, personal email domains, instant selection claims) while 
  rewarding legitimate signals (e.g., structured interview rounds, official 
  career portals, specific technical skill requirements).
* Manual Listing Checker: Paste any suspicious WhatsApp message, email, or 
  social media job post to immediately analyze it for scam indicators.
* Smart Classification: Uses Claude AI (when an Anthropic API key is provided) 
  or falls back to a built-in keyword classifier to verify that listings are 
  genuine internships matching your selected field.
* Sample Mode: Works out-of-the-box with built-in mock data if no API keys are 
  configured.


PROJECT STRUCTURE
-----------------
* app.py            - Flask backend, Adzuna API integration, AI/keyword 
                      classifier, and weighted scam-scoring engine.
* index.html        - Single-page frontend with responsive UI and dark-mode 
                      support.
* requirements.txt  - Python dependencies (Flask, Requests, python-dotenv).
* .env              - Local environment variables (ignored by Git).


SETUP & INSTALLATION
--------------------
1. Clone or download the project files into a local directory.

2. Create and activate a virtual environment (recommended):
   python -m venv venv
   
   # On Windows:
   venv\Scripts\activate
   
   # On macOS/Linux:
   source venv/bin/activate

3. Install the required dependencies:
   pip install -r requirements.txt

4. Configure your environment variables:
   Create a `.env` file in the root directory and add the following keys:

   ADZUNA_APP_ID=your_adzuna_app_id
   ADZUNA_APP_KEY=your_adzuna_app_key
   ADZUNA_COUNTRY=in
   USE_MOCK=false

   # Optional: Enable AI-based role & category classification
   ANTHROPIC_API_KEY=your_anthropic_api_key
   CLAUDE_MODEL=claude-haiku-5-5

   Note: If `USE_MOCK=true` or Adzuna credentials are omitted, the app will 
   automatically run using built-in sample listings.

5. Run the application:
   python app.py

6. Open your browser and navigate to:
   http://127.0.0.1:5000


SECURITY NOTE
-------------
Never commit your `.env` file or expose live API keys in public repositories. 
Ensure `.env` remains listed in your `.gitignore` file.


DISCLAIMER
----------
The trust scores generated by Internship Radar are heuristic risk indicators, 
not a guarantee of legitimacy. Always verify companies through their official 
websites and never pay money to apply for an internship. Job data powered by 
Adzuna.
